## Descripción general

Este repositorio contiene los materiales para el curso taller
“Introducción al uso de registros nacionales de salud para
investigación”, que se llevará a cabo el jueves 10 de septiembre 2026 en
Lima, Perú.

Para mayor detalle, vea la [página de
bienvenida](https://sdca-latam.github.io/curso-registros-esp/).

> [!TIP]
>
> Este repositorio de taller fue generado con la plantilla
> [`template-workshop`](https://github.com/rostools/template-workshop)
> del proyecto rostools.
